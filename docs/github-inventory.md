# GitHub-inventering för portfolion

Granskning: 2026-09-28. Inventeringen omfattar 15 tillgängliga projekt utöver själva portfolion: 11 under det egna kontot, två organisationsrepon och två samarbetsrepon.

## Metod och avgränsning

GitHub API användes för att inventera standardbranchernas filträd i samtliga repon. 131 Markdown- och HTML-dokument hämtades som läsunderlag, med andra medlemmars personliga mappar och applikationsmallar undantagna. Båda individuella slutrapporterna lästes, tillsammans med centrala README-filer, personlig GKE-dokumentation, infrastruktursammanställning och teamets bidragsfördelning för ML-projektet. Alla hämtade dokument har inte detaljgranskats rad för rad.

Detta är en bred portfolio- och innehållsgenomgång, inte en fullständig kodrevision. Binärfiler, skärmdumpar, samtliga historiska commits, övriga brancher och alla issues/PR:er har inte detaljgranskats. Projekt som kontot inte längre har åtkomst till kan saknas. Forkar jämfördes med sina föräldrars standardbranch för att undvika att tillskriva Jonny mallarnas hela funktionalitet.

## Profil som framträder

Den publika AIS-reflektionen beskriver ett intresse för SOC Analyst, Security Engineer och detection engineering. Projekturvalet lyfter därför SIEM, OT och integrationsarbete först, med molninfrastruktur och DevSecOps som kompletterande bredd. Det är utbildningserfarenhet; yrkesanställning och expertgrad antas inte.

## Komplettering från Jonny

Utbildningsnamn, period, yrkeserfarenhet och kontaktuppgifter har därefter bekräftats genom Jonnys CV-underlag. Aktuell målroll och tillgänglighet för LIA/anställning återstår att precisera. Webbplatsen länkar till publika beskrivningar av arbeten vars kod är privat.
